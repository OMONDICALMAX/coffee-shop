## Savanna Coffee House

A simple React-based coffee shop web application with an admin portal and dynamic product display system.

## Features

 Home page with brand introduction
 Shop page displaying coffee products in a responsive grid
 Admin portal to add new coffee products
 Dynamic data flow between Admin → Shop
 Clean and modern UI with hover effects and animations
 Responsive layout using CSS Grid and Flexbox


## Tech Stack

 React (Vite)

 JavaScript
 CSS
